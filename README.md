# Skate.FM Submissions — Bug Reports & Feature Requests

Public repository for bug reporting and user issue tracking for the Skate.FM DJ Submission Portal at [subs.skate.fm](https://subs.skate.fm).

The portal source code lives in a private repository. This repo exists only so DJs, staff, and admins can file bug reports and feature requests in the open without needing access to the production codebase.

## Reporting a bug

1. Open [a new issue](https://github.com/SkateFM/skate-fm-subs-public/issues/new/choose).
2. Pick the **Bug Report** template.
3. Fill in what happened, what you expected, and how to reproduce it.
4. Include a screenshot if the bug is visual.

## Requesting a feature

Pick the **Feature Request** template when opening a new issue.

## What to include

The faster a bug gets fixed depends almost entirely on how reproducible it is. Helpful info:

- **What you were doing** when the bug happened (e.g. "uploading a mix on the Curation Desk")
- **Browser and device** (e.g. Chrome on macOS, Safari on iPhone)
- **The full URL** in the address bar when it broke
- **Screenshot** of the problem, especially of any error messages
- **Console errors** if you're comfortable opening DevTools (F12 → Console tab)

## What to leave out

Please **don't** include:

- Passwords or auth tokens
- Other DJs' private email addresses
- Music files or submission contents

## Status & response time

This is a small team. We triage reports as they come in. The portal is currently in **beta** so expect some rough edges — your reports are how we find them.

## Security issues

If you've found a security vulnerability, **don't open a public issue**. Email security@skate.fm directly so we can fix it before it's disclosed.
